    This lookup checks the state’s curriculum inventory codes only. The Fresh Success Handbook (Part IV, pp. 21–22) also lists other permissible courses, for example courses that are required, a prerequisite, recommended or an elective in a student’s declared CTE program, career-oriented counseling and basic skills courses (including TOP codes 4930 and 4931), and approved customized courses of study. If a course does not pass here but you think it may qualify through one of those routes, confirm with the Foundation for California Community Colleges.

    How eligibility is decided

    Programs
    Program eligibility rules
    What the tool checksEligible when
    TOP codeThe TOP code has an asterisk (*). An asterisk marks a career technical education (CTE) program.
    StatusThe program is Active or Approved. Inactive, Teachout Only, Draft, Revision and Review programs are not eligible.
    Courses
    Course eligibility rules
    What the tool checksEligible when
    StatusThe course is Active. Only active courses are eligible.
    TOP codeThe TOP code has an asterisk (*), which marks a CTE course.
    SAM priority codeA, B or C: occupational, passes. D (Possibly Occupational): shows a caution because the course may or may not be eligible; with an asterisk in the TOP code it is likely eligible. E (Non-occupational): not eligible.
    Noncredit categoryApplies to noncredit courses only. Eligible categories: A (English as a Second Language), C (Elementary and Secondary Basic Skills), I (Short-term Vocational) and J (Workforce Preparation). Not eligible: B (Citizenship for Immigrants), D (Health and Safety), E (Courses for Persons with Substantial Disabilities), F (Parenting), G (Home Economics), H (Courses for Older Adults). Credit courses are not judged on this item.

    A course must pass every check. If a code is missing or not recognized, the tool says “Cannot determine” instead of guessing.

    Where the code names come from

    Code names are from the California Community Colleges Chancellor’s Office Data Element Dictionary: CB09 Student Accountability Model (SAM) Priority Code and CB22 Noncredit Category. Program and course records come from the Chancellor’s Office Curriculum Inventory (COCI).

    How current is this information?

    This tool supports planning and eligibility screening. The data comes from COCI exports, and colleges should confirm any funding decision with the Foundation for California Community Colleges. If a result looks wrong, contact your Fresh Success implementation coach.
